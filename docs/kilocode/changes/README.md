# Система документирования изменений

## Назначение

Автоматическое документирование изменений кода темы недвижимости.

## Структура

```
changes/
├── README.md         # Этот файл
├── SCOPES.md        # Справочник всех скоупов
├── diary/           # Хронологический дневник
│   └── YYYY/
│       └── MM/
└── tags/            # Теги по компонентам
    └── <scope>.md
```

## Использование

### Скоупы

Скоуп — это метка компонента для группировки изменений.

Формат: `тип.имя` (нижний регистр, точки как разделитель)

Примеры:
- `feature.property` — PropertyFeature
- `ajax.property_filter` — AJAX фильтрация
- `vue.property-filter` — Vue компонент

### Теги

При изменении кода тега обновляется файл `tags/<scope>.md`.

### Дневник

Хронологическая запись всех изменений: `diary/YYYY/MM/YYYY-MM-DD.md`

## Основные скоупы

- `feature.property` — основная фича недвижимости
- `core.realtycore` — базовый класс темы
- `ajax.property_filter` — фильтрация AJAX
- `shortcode.property_filter` — шорткод фильтра
- `helper.gallery` — работа с галереями Pods
