### feature.property - Исправление игнорирования GET-параметров

- **Скоуп:** `feature.property`
- **Файл:** `wp-content/themes/realty-theme/template-parts/content/list/property-card-list.php`
- **Описание:** Удалён дублирующийся код обработки GET-параметров. Теперь используется централизованный метод `property_filter_render_list()` без параметров, который автоматически берёт фильтры из GET через `formatRequestParams('GET')`. Это устраняет дублирование логики и обеспечивает корректную обработку URL-параметров при загрузке страницы архива недвижимости.
- **Решённая проблема:** GET-параметры (location, location_slug, checkin_date, checkout_date, adults, children) игнорировались при начальной загрузке страницы
